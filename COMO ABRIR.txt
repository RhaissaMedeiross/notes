MEU CADERNO - STUDY STUDIO (WINDOWS)

1. Instale o Node.js LTS em https://nodejs.org/ (apenas uma vez).
2. Extraia todo o ZIP em uma pasta permanente, por exemplo Documentos/Meu Caderno.
3. De dois cliques em "Abrir Meu Cantinho.bat" na pasta extraida.
4. Com Edge ou Chrome em local padrao, o app abre em janela propria.
   Se nao encontrar esses navegadores, usa o navegador padrao.
5. Mantenha a janela do servidor aberta enquanto estiver estudando.
6. Para criar um atalho: botao direito no arquivo .bat > Mostrar mais opcoes >
   Enviar para > Area de trabalho (criar atalho).

PARA ATUALIZAR: baixe um Backup no app antigo, feche a janela do servidor
antigo e depois abra a nova versao. Use o mesmo navegador e perfil.
As notas ficam neste navegador; baixe backups regularmente.

Use Personalizar para escolher temas rosa, gotico e Y2K, mudar cores,
fontes, nome, frases e layout. Use a aba Inserir para codigo e checklists.
Os blocos de codigo sao anotacoes: nao executam programas.
Nao e necessario npm install. Para outros sistemas, use npm start na pasta.
O lancador Windows ainda precisa ser verificado no seu computador.
